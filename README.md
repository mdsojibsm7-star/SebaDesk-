# SebaDesk- (সেবাডেস্ক)

> **SebaDesk** — All-in-One Offline-First Digital Service, Passport Photo & Document Studio.
> নাগরিক সেবা, চাকরির আবেদন, পাসপোর্ট/স্বাক্ষর সাইজ ছবি তৈরি এবং মাইক্রোসফট ওয়ার্ডের মতো মাল্টি-পেজ ডকুমেন্ট স্টুডিও।

---

## 🌟 মূল ফিচারসমূহ (Core Features)

### 1. 🌐 Portal Hub (ডিজিটাল সেবা পোর্টাল)
- **সরকারি ও নাগরিক সেবা:** NID Wing, e-Passport, BDRIS জন্ম ও মৃত্যু নিবন্ধন, BRTA সেবা, ভূমি সেবা (Land.gov.bd), পুলিশ ক্লিয়ারেন্স ও আয়কর (NBR e-Return)।
- **চাকরি ও শিক্ষা:** Teletalk All Jobs, BPSC, Bdjobs, Education Board Results, জাতীয় বিশ্ববিদ্যালয় (NU), মুক্তপাঠ।
- **স্মার্ট সিকিউর ভিউয়ার:** ইন-অ্যাপ ব্রাউজার উইন্ডো, ব্যাক/ফরোয়ার্ড কন্ট্রোল এবং অফিসিয়াল পোর্টালে সরাসরি যাওয়ার স্মার্ট লঞ্চার।

### 2. 📸 Photo Studio Pro (পাসপোর্ট ও স্বাক্ষর স্টুডিও)
- **সরকারি প্রিসেট:** Passport Size (300×300 px), Signature (300×80 px), NID / Visa (400×500 px) এবং কাস্টম সাইজ + রেশিও লক।
- **Face-Safe Background Swap:** মুখের ওপর রঙ যাওয়া ছাড়া ১-ক্লিকে সাদা, নীল বা DSLR বোকেহ ব্যাকগ্রাউন্ড পরিবর্তন।
- **ইন্টারঅ্যাক্টিভ ক্রপ ও রোটেট:** ছবির ওপর ড্র্যাগ করে ক্রপ বক্স, -90°/+90° রোটেশন, ফ্লিপ ও সোজা করার সুবিধা।
- **অটো এনহ্যান্স ও ফিল্টার:** ১-ক্লিকে ছবির উজ্জ্বলতা ও শার্পনেস বাড়ানো।
- **<100KB কম্প্রেসর:** মেমোরিতে HTML5 Canvas দিয়ে সরাসরি কাঙ্ক্ষিত সাইজে (<100KB / <60KB) সেভ ও ডাউনলোড।

### 3. 📄 Doc Studio (মাল্টি-পেজ ওয়ার্ড স্টুডিও)
- **Microsoft Word-এর মতো মাল্টি-পেজ এডিটর:** প্রয়োজন অনুযায়ী Page 1, Page 2 যোগ করা, ডুপ্লিকেট করা ও পেজ সাজানো।
- **MS Word Ribbon Toolbar:** হেডিং, ফন্ট সাইজ (A+/A-), টেক্সট কালার, হাইলাইটার কালার, টেবিল মেকার (Rows × Cols), ছবি বা স্বাক্ষর ইনসার্ট, তারিখ ও ডিভাইডার।
- **রেডিমেড বাংলা ও ইংরেজি টেমপ্লেট:** ছুটির দরখাস্ত, চাকরির আবেদনপত্র, ১ ও ২ পাতার পেশাদার CV / বায়োডাটা।
- **প্রিন্ট ও ওয়ার্ড এক্সপোর্ট:** ১-ক্লিকে সরাসরি প্রিন্ট (`window.print()`) এবং `.DOC` ফাইল ডাউনলোড।

### 4. 🗄️ Offline Vault (অফলাইন ভল্ট)
- ঘন ঘন ব্যবহার করা ঠিকানা, এনআইডি নম্বর, সার্টিফিকেট তথ্য ও টেমপ্লেট লোকাল স্টোরেজে নিরাপদে সংরক্ষণ।
- ১-ক্লিকে কপি ও সরাসরি ডকুমেন্ট এডিটরে পাঠানোর সুবিধা।
- JSON ব্যাকআপ এক্সপোর্ট ও ইমপোর্ট।

## 🚀 লোকাল রান করার নিয়ম (How to Run Locally)

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# ৩. প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

ব্রাউজারে ওপেন করুন: `http://localhost:5173/`

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (Dark Mode & Print Styles)
- **Icons:** Lucide React
- **Engine:** HTML5 Canvas API + LocalStorage
